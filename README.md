# ub

Quality gates and UML viewers for agent-assisted development — **companion forks** under [Noodle-cpp](https://github.com/Noodle-cpp).

[Русская документация](README.ru.md) · [Full workflow (RU)](POLNY-CIKL-UB.ru.md)

## Companion repositories

| Tool | Repository |
|------|------------|
| **crapper** — CRAP, complexity, coverage | [Noodle-cpp/crapper](https://github.com/Noodle-cpp/crapper) |
| **mutator** — mutation testing | [Noodle-cpp/mutator](https://github.com/Noodle-cpp/mutator) |
| **dryer** — structural duplication | [Noodle-cpp/dryer](https://github.com/Noodle-cpp/dryer) |
| **uml-viewer** — Clojure UML + agent mailbox | [Noodle-cpp/uml-viewer](https://github.com/Noodle-cpp/uml-viewer) |
| **ub-mode** — agent skill (quality discipline) | [Noodle-cpp/ub-mode](https://github.com/Noodle-cpp/ub-mode) |
| **uml-viewer-dotnet** — Avalonia viewer (no JVM) | local checkout beside other clones; see `uml-viewer-dotnet/README.md` |

Upstream lineage: [unclebob](https://github.com/unclebob) (crapper, mutator, dryer, uml-viewer). These forks track companion workflows and C# / .NET additions.

## This repository

Tracks the **workspace guide** only. Tool source lives in the repos above; clone them into one folder (e.g. `ub/crapper`, `ub/uml-viewer`) for the layout described in [POLNY-CIKL-UB.ru.md](POLNY-CIKL-UB.ru.md).
